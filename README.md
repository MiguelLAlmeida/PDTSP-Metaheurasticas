## 📝 Descrição

O projeto tem por objetivo a implementação de dois algorítimos de busca local para solução do Problema do Caixeiro Viajante, sendo estes o Iterative Local Search (ILS) e o Biased Random Key Generator Algorithm (BRKGA), bem como uma comparação entre os níveis de eficiência das duas metaheurísticas.
